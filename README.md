# 🏠 Sharma Properties – Real Estate Website

A modern, fully responsive real estate website for **Sharma Properties**, a RERA‑registered agency in Dwarka, Delhi. The platform allows users to browse, filter, sort, and view detailed property listings, contact the agent, schedule visits, and submit enquiries – all with a professional, fast, and SEO‑friendly frontend.

## 📋 Features

- **Property Listing**: Search by title/location, filter by type (sale/rent), BHK, price range, and sort by price (low/high).
- **Pagination**: 6 properties per page with numbered navigation.
- **Property Detail Page**: Image gallery, full specs (society, furnishing, facing, area, floor, parking, age, amenities, nearby connectivity), lead panel, map, and similar properties.
- **Responsive UI**: Works seamlessly on mobile, tablet, and desktop – no horizontal overflow.
- **Sticky Navbar with Animations**: Smooth mobile menu, scroll‑based background blur, active link highlighting.
- **Footer**: 4 columns, clickable links, social icons, RERA info, and “Made by Archinova” credit.
- **WhatsApp Chat Button**: Fixed bottom‑right button (customisable message).
- **Contact Page**: Contact info + enquiry form (opens WhatsApp with prefilled message).
- **About Page**: Stats row (experience, families served, etc.), owner profile, RERA badge.
- **Loading Animation**: Full‑screen glass morphism loader (2 seconds) on route changes.
- **Scroll‑to‑Top**: Automatically scrolls to top on every navigation.
- **SEO Optimised**:
  - Meta tags (title, description, keywords, Open Graph, Twitter)
  - JSON‑LD structured data for local business (RealEstateAgent)
  - Custom favicon + apple touch icon
  - Canonical URL and geo tags

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Routing**: React Router DOM v6
- **Styling**: Pure CSS (no Tailwind) – each component has its own CSS file
- **Icons**: Lucide React (partial) + custom SVGs for social media
- **State Management**: React hooks (useState, useEffect)
- **Data**: Static JSON files (siteConfig, properties, testimonials, teamMembers)
